Connect To GitHub

This is what actually lets Save write changes to your live site. Enter a token once — it's remembered in this browser only.

First time? Create a token:
  1. Go to github.com/settings/tokens?type=beta and click "Generate new token".
  2. Under Repository access, choose "Only select repositories" and pick mrmaple-tech/NFC.
  3. Under Permissions → Repository permissions, set Contents to "Read and write".
  4. Set an expiration (90 days is reasonable — you'll just generate a new one after), then click Generate.
  5. Copy the token (starts with github_pat_) and paste it below. GitHub only shows it once.
Keep this token private — anyone who has it can edit your repo. Only paste it into this page, on a device you trust.

Edit Site Data

Pick what you want to update. This loads the exact same plain-English data block you'd normally hand-edit — change the values, then Save pushes it straight to the live site.

Keep the same shape (commas, quotes, curly/square brackets). Save checks that it's still valid before publishing. After saving, GitHub rebuilds the site automatically — usually live within a minute or two. Check "Deployment Status" to watch it.
